# 開発ベース

この名前は既存の呼び出しをpstack-claudeベースの標準フローへ接続する入口。
[poteto-mode](../poteto-mode/SKILL.md) を読み、依頼に合うplaybookを選んで進める。

ユーザーの実行指示書・変更範囲・禁止事項を引き継ぎ、独立した調査・設計・実装・レビューと実物の検証を適用する。同じ工程を旧フローと二重に実行しない。

既存の `references/` は、要件・縦切り・設計の補助資料として保持する。必要な資料だけを使い、標準手順はpoteto-modeへ集約する。
