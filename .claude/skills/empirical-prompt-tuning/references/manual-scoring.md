# manual-scoring

`scripts/ept_score.py` が実行できない時だけ参照する。

1. 各シナリオの `[critical]` 要件を確認する。
2. `[critical]` が全て `ok` のシナリオを成功にする。
3. `ok=1`、`partial=0.5`、`ng=0` として全要件平均の精度を出す。
4. 各回2本以上の同じシナリオ・同じ固定要件があり、全critical要件を満たしていることを確認する。要件のtextは空欄・重複を認めず、文言・順序・critical指定を固定する。欠測は0と扱わない。
5. 直近2回で、新規不明瞭点0件、精度悪化なし・改善+3pt以下、steps変動±10%以内、duration変動±15%以内を確認する。
6. 上記条件を2遷移連続（最低3回の実行）で満たした時だけ停止判定にする。未実施や安定した失敗を収束扱いしない。
7. 重要なskillでは未使用のhold-outを別枠で評価する。通常評価の収束計算に混ぜず、最終iterationの通常シナリオ平均と精度を比較する。15ポイント以上の低下、またはcritical未達なら不合格。通常評価の収束とhold-out合格の両方を必要とし、hold-out未実施を合格にしない。
