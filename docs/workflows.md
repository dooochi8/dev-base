# pstack-claudeを基盤にした開発フロー

通常は `poteto-mode` に目的・対象・制約・完了条件を渡す。モードが依頼をplaybookへ分類し、必要なスキルを選ぶ。ユーザーが毎回スキルの順番を指定する必要はない。

本文と入口は日本語。上流の手順と参照資料は原文を保持し、[実行対応](../poteto-mode/references/runtime.md) でCodex/Claude・Linear・検証・保存先を接続する。[採用範囲と版](pstack-adoption.md) を参照。

## 依頼と手順

| 依頼 | playbook | 主な工程 |
|---|---|---|
| 仕組み・理由・方針の相談 | investigation | how / why、必要な根拠の調査、読み取りで回答 |
| バグ修正 | bug-fix | 実際の操作で再現、仮説を切り分け、修正、同じ再現条件で検証 |
| 機能追加・振る舞い変更 | feature | how、architect、分担の境界を決める、実装、実物の検証、PR |
| 振る舞いを保つ構造変更 | refactoring | 契約と呼び出し元を確認、構造を変更、回帰確認 |
| 計測した性能問題 | perf-issue / hillclimb | 基準値、仮説、実験、前後の計測 |
| 大きな移行・既存手順に合わない仕事 | figure-it-outから独自手順 | 受入条件、仮説と実験、検証可能な単位、判断記録 |
| PRのCI・指摘・競合への継続対応 | babysit | 依頼された範囲で状態を取得し、修正と再検証 |
| 長い複数PRの運用 | orchestrate / autopilot | 担当・依存・作業場所を分離し、各成果を検証 |
| 作業の中断・再開 | pause-safely / session-pickup | 証拠と現在状態を記録し、再開時に実ファイルと照合 |

23種類の全手順は `poteto-mode/playbooks/` に保持している。原文が要求する別担当・複数案比較は、実行環境と上位指示が許す範囲で行う。省略や代替の理由を残し、同じモデルの別実行を複数モデル比較と呼ばない。

## 既存スキルの役割

| スキル | pstackから使う場面 |
|---|---|
| dev-base | 既存名からpoteto-modeを呼ぶ入口 |
| orient | 未知のリポジトリの入口を短く把握する補助。howと同じ調査を繰り返さない |
| grill-me / grilling / write-a-prd | 実験で決められない要件・業務判断を確定する |
| plan-eng-review / plan-design-review | 求められた技術設計・画面や導線のレビュー |
| prd-to-issues / plan-handoff | 要件を成果単位のIssueへ分ける、実際の担当へ引き継ぐ |
| debug | 再現・仮説・切り分けの具体的な補助 |
| verify | 必要なチェックと実物の動作を根拠に完了を判断する |
| review-diff | 小さな差分のレビュー。独立した厳しいレビューはinterrogate |
| search-first / security-review | 新しい依存や外部連携の比較、変更する信頼境界の確認 |
| show-me / smart-docs | 図解、コードに基づく設計文書 |
| Emilスキル群 | UI・操作感・動きの実装やレビュー。導入済みのスキルを用途に合わせて選ぶ |
| empirical-prompt-tuning | スキル・指示の独立した実行評価 |
| project-start / linear-workflow | 新規環境の準備、開発の目的・状態・完了条件の管理 |

スキルの導入を、そのスキルの対話・評価・外部操作の実行依頼と混同しない。ユーザーのレビューだけの依頼を実装へ変えない。

## 担当と完了

主担当は調査結果から設計を選び、担当の差分と証拠を自分で確認する。複数の書込担当はworktreeや出力先を分ける。独立した調査・検査は並行し、依存する工程と同じ対象への書込は順に行う。

開発の目的・状態はLinear、仕様と設計判断はdocs、コードとレビューはGit/GitHub。検証後に人の受入確認が残る時はIn Reviewへ進める。PRマージだけを完了としない。

UI・CLI・サービスは対象に合った操作で確認する。自動試験、静的検査、動作確認、独立レビューを区別し、未実施のものは未実施と報告する。新しい差分や失敗・懸念がない限り、合格した同じ検査を繰り返さない。
